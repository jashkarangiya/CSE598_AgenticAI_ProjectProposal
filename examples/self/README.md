# Reports about SlopGate itself

Two reports describing this repository's own Python source, so the tool can be
run against a real checkout rather than only the bundled C toy:

    python3 slopgate.py examples/self/

`grounded.md` describes a real function. `invented.md` describes one that does
not exist. Neither is a real vulnerability report; `invented.md` in particular
is a deliberately false claim, kept here as test input.
